# Results

Place **newly reproduced** evaluation results here after training. Do not commit raw student responses, dataset files, leaderboard data or private outputs.

Suggested report fields:
- dataset version/source and access date;
- split method, random seed and number of examples;
- model checkpoint and configuration;
- accuracy, MAE, MSE, Cohen's kappa and QWK;
- confusion matrix and per-class precision/recall/F1;
- hardware and software versions;
- limitations and any prompt-held-out results.

Historical figures from the 2024 write-up must be clearly labelled as historical until reproduced.
