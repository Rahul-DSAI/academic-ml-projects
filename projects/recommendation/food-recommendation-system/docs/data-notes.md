# Data notes

The provided CSV files contain 38 candidate menu items and 13 preference examples. The candidate file has 12 columns; the preference file has the same fields except `UserRating`. The inspected CSVs have no missing values and no duplicate `foodItemName` values in the 38-item catalogue.

The project includes the two small user-supplied CSV files to make the example runnable. Their original data provenance/licensing is not stated in the supplied archives. Before publishing this repository publicly, verify that you have the right to redistribute the menu text, restaurant names and ratings. If not, replace these files with a dataset you are permitted to share and update the README paths.
